    Forced RLS

    Eight tenant tables carry policies. The app role is NOBYPASSRLS, so a missing WHERE clause still cannot leak rows.

    Rotating sessions

    Access tokens live 15 minutes. Refresh tokens rotate on every use; replay revokes the whole family.

    Roles & seats

    Owner, admin, manager and member are checked by API guards and mirrored in the interface. Seats cannot be oversold.

    BYOK vault

    A master key wraps each tenant's data key. Secrets are sealed with AES-256-GCM and returned masked.

    Rate limits

    Per-plan request budgets use Redis counters and a burst allowance, with retry hints on rejection.

    Append-only audit

    Every tenant mutation records actor, action, entity, IP and request id inside the same RLS context.
